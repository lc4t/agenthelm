agents-init v6

创建或迁移通用项目骨架与 Project Profile；写入前验证随包的 project-orchestrator、agent-pack 与 opinion-manager。

状态stable

资源入口

AI 原文 执行入口与初始化流程，适合 Agent 直接读取。 机器元数据 版本、路径、标签、输入输出等结构化信息。 模板文件 v6 骨架契约、职责边界与迁移规则。

文件分工

文件 作用
SKILL.mdAI Agent 的执行入口，说明触发方式、流程和必读文件。
AGENT.template.md项目骨架、Project Profile 与迁移契约。
skill.json机器可读元数据，用于索引、安装、版本检查和自动发现。
index.html浏览器可读页面。

适用场景

  • 新仓库需要统一的 Agent 入口与 Project Profile。
  • 旧版 agents-init 项目（含 v5 project-runtime Profile）需要迁移到 v6 职责边界。
  • 项目准备通过 project-orchestrator 管理 Task/Case 与 Git，通过 agent-pack 管理 Skill 与 MCP，通过 opinion-manager 管理 Agent 行为规则。
  • 公开模板需要排除个人规则、凭据与私有路径。

输入信息

字段 必填 说明
项目名称是仓库或产品的名称。
项目类型是代码、文档、工作流或其他可组合类型。
技术栈是可从仓库文件确认的语言与框架。
运行环境是本地、容器、远程或混合。
Agent 客户端是Codex、Cursor、Claude Code 等入口。
项目命令否不能确认时保留 TODO，不由模板臆造。

标准流程

  1. 扫描仓库并确认可证实的 Project Profile 字段。
  2. 预览 v6 文件计划和所有路径冲突。
  3. 确认后运行无覆盖初始化器。
  4. 解析 JSON 并检查 Agent 路由一致性。
  5. 由随包 agent-pack 后续导入或同步 Skill/MCP。
  6. 由随包 opinion-manager 提供直接用模板、选择部分条目、从空白开始；另可基于已授权记忆提出候选。完整内容集中确认。
