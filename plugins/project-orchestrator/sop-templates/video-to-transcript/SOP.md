# {{title}}

## 目的

把一个视频转成可阅读、可检索的文字稿，并保留来源信息。

## 前置条件

下面是一组常见选择，名称都是示例：请按你实际使用的工具逐项确认、替换或删除。带“仅当”的项只在本次输入符合条件时才需要。

- 命令：yutto｜用途：下载 B 站视频（BV / av 号、bilibili.com 链接），可用 `--audio-only` 只取音频、`-d` 指定输出目录｜安装：`pipx install yutto`（需要已配置 FFmpeg）｜仅当：输入是 B 站视频｜缺失时：询问用户
- 命令：yt-dlp｜用途：下载其他网站的在线视频｜安装：`pipx install yt-dlp` 或系统包管理器｜仅当：输入是 B 站以外的在线视频｜缺失时：询问用户
- 命令：ffmpeg｜用途：合并 B 站音视频流、从视频提取音频、转成转录工具需要的格式｜安装：系统包管理器（如 `brew install ffmpeg`）｜缺失时：询问用户
- 命令：whisper-cli｜用途：本地模型转录｜安装：按所用的本地转录工具的官方说明｜替代：TRANSCRIBE_API_KEY｜缺失时：使用替代
- 路径：~/models/whisper.bin｜用途：whisper-cli 需要的模型文件，请改成你的实际位置｜缺失时：询问用户
- 环境变量：TRANSCRIBE_API_KEY｜用途：改用云端转录 API 时的密钥（只写变量名）｜缺失时：询问用户

## 步骤

1. 确认输入与选项
   - 输入：视频链接或本地文件路径；语言；是否需要时间戳
   - 检查点：输入明确，本地文件确实存在
2. 取得视频文件
   - 工具：yutto、yt-dlp
   - 输入：视频链接（本地文件则跳过本步）
   - 中间产物：下载的视频或音频文件
   - 检查点：文件存在且大小大于 0
   - 失败时：询问用户（链接失效、需要登录或地区限制时不要自行绕过）
   - 需确认：是
   - 说明：B 站链接用 yutto，其他站点用 yt-dlp。需要登录才能看的内容，由用户自己登录并保存登录信息（yutto 的做法见其官方文档），登录凭据不写进本 SOP、不写进 Case。大文件下载属于耗时步骤，按“执行约定”决定是否先问
3. 提取音频
   - 工具：ffmpeg
   - 输入：上一步的视频或音频文件
   - 中间产物：audio.wav（单声道，16 kHz；转录工具要求其他格式时按其要求）
   - 检查点：音频时长与视频时长相差不超过 1 秒
4. 转录
   - 工具：whisper-cli、TRANSCRIBE_API_KEY
   - 输入：audio.wav；语言
   - 中间产物：原始转录结果
   - 检查点：文本非空，长度与音频时长大致匹配
   - 说明：优先使用本地转录；本地不可用且用户同意时才改用云端 API，使用 API 会把音频发送给第三方服务，需要先问用户
5. 整理与保存
   - 输入：原始转录结果
   - 最终产物：文字稿（保存位置见完成标准）
   - 检查点：抽查开头、中间、结尾各一段与音频一致
6. 清理
   - 说明：按“执行约定”处理中间产物；只清理本次在 Case 里登记过的文件

## 完成标准

- 文字稿已保存到：【待补充】
- 文字稿开头记录了来源（链接或文件名）、转录工具与日期
- 中间产物已按约定处理，处理结果记在 Case 的工作记录里

## 例外与回退

- 视频无音轨：停止并告诉用户，不要凭空生成文本
- 音频很长：可按段切分转录再合并，合并后检查段落衔接
