agenthelm

跨 Agent 的项目管理插件集：agents-init 初始化项目，project-orchestrator 管理 Case 与生命周期，agent-pack 管理扩展能力并负责检查与更新，opinion-manager 管理用户确认的 Agent 行为规则。Claude Code、Codex、Cursor 读取同一份市场清单。

Plugin 6.5.0

安装

四个插件须一并安装。任意客户端：先预览，确认后执行（需要 Node 18+ 与 Python 3.11+）。

npx @sakanano-moe/agenthelm install
npx @sakanano-moe/agenthelm install --apply

Claude Code：claude plugin install agents-init --marketplace lc4t/agenthelm，会一并安装另外三个依赖插件。

Codex：codex plugin marketplace add lc4t/agenthelm，再 codex plugin add <插件>@agenthelm；添加市场后可在桌面端打开下方链接查看并安装。

Cursor：npx @sakanano-moe/agenthelm install --client cursor --apply，重启生效；Teams / Enterprise 可在 Dashboard 导入本仓库为团队市场。

在 Claude Code 中打开（实验） 在 Codex 中打开 Agent 安装说明 市场清单

检查与更新：npx @sakanano-moe/agenthelm check 只读报告；npx @sakanano-moe/agenthelm update 预览，确认后 --apply。会话开始时每天至多检查一次，AGENTHELM_NO_UPDATE_CHECK=1 可关闭。

Skill 目录

agents-init v6 / Project Profile 初始化与迁移

创建或迁移通用项目骨架，并在写入前验证随包的 project-orchestrator、agent-pack 与 opinion-manager；可把 v5 Profile 升级到 v6。

SKILL.md AI 执行入口：触发条件、必读文件和初始化流程。 AGENT.template.md 独立模板：v6 骨架契约、职责边界与迁移规则。 skill.json 机器索引：版本、入口路径、文件角色和命令。
浏览 Skill 模板 JSON

project-orchestrator / 项目生命周期编排

读取项目契约，选择最小 Task / Case，把工作路由给确定性 Tool 与叶子 Skill，再完成验证、进度记录与受控 Git 交付。

SKILL.md AI 执行入口：项目生命周期、能力路由与职责边界。 plugin.json 独立 Plugin manifest。
Skill Plugin

agent-pack / Agent 扩展能力管理

在项目与 Codex / Cursor / Claude Code 之间盘点、校验、安装、同步、迁移与对账 Plugin、Skill、MCP；附带 CLI 与 MCP server。

SKILL.md AI 执行入口：何时盘点、同步或迁移能力。 能力配置参考 Agent Plugin、Skill 与 MCP 的盘点、迁移和同步契约。 mcp.json agent-pack MCP server 清单。
Skill Plugin

opinion-manager / Agent 行为规则管理

通过直接用模板、选择部分条目或从空白迭代生成和维护统一的 OPINION.md。公开目录提供经过批准的可选规则与平行变体；另可基于已授权记忆提出候选。个人配置经完整预览、一次内容确认后分别保存并核验。

SKILL.md 三个主入口、可选记忆候选、一次内容确认、升级与模板准入流程。 opinion_manager.py 模板目录、规则选择、预览和写入工具。
Skill Plugin

机器索引

Agent 首选读取 llms.txt；安装工作流位于 INSTALL.md；全站索引位于 index.json。

新增规则

  • 每个 skill 独立目录。
  • 固定包含 SKILL.md、skill.json、index.html。
  • 模板类 skill 可追加同级模板文件，例如 AGENT.template.md。
  • assets/ 非必需，只在资源文件较多时创建。
  • 版本与更新记录写入 CHANGELOG.md。
